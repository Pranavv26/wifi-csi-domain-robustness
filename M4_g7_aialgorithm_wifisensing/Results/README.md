# Results (M4)

Results for the M4 study of DATTA on Widar3.0-G6D with WiFlexFormer. Test = 30,749 held-out samples (room 1); metric = macro-F1.

- `all_training_runs.csv`: source-validation and Test results of every training run (8, 15 and 30 epochs).
- `training_length_pairs.csv`, `training_length_summary.json`: training-length comparison (W, W+aug, W_DAT).
- `adaptation_results.csv`: W_DAT with no adaptation, TTA and DATTA for the 15- and 30-epoch models.
- `per_class_recall_30ep.csv`: per-class recall of the 30-epoch models.
- `sec_per_epoch.json`: training speed per machine.
- `test15_*.json`, `test30_*.json`: raw TTA/DATTA outputs (accuracy, precision, recall, F1, confusion matrix, per-sample predictions).
- `figures/`: figures used in the report.

All tables and figures are generated by `Code/make_m4_assets.py`.
